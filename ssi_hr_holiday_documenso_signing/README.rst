================================================
HR Holiday - Documenso Signing Integration
================================================

This module integrates **HR Leave** (``hr.leave``) and **HR Leave Allocation**
(``hr.leave_allocation``) with **Documenso**, an open-source digital signature
platform.

It adds a *Documenso* tab to both the HR Leave and HR Leave Allocation form
views, allowing users to manage signature requests directly from each record.

Configuration
=============

No additional configuration is required. Install this module along with
``ssi_connector_documenso_signing`` and configure the Documenso connector
through the system settings.

Usage
=====

Open any HR Leave or HR Leave Allocation record. A new **Documenso** tab will
appear in the form view, listing all signature requests linked to that record.
