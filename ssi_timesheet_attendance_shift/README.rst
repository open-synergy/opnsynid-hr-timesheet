==========================
Timesheet Attendance Shift
==========================

Adds the ``hr.attendance_shift`` master data model, expressing a work
shift as a start hour plus a duration so that a shift crossing midnight
(e.g. 18:00-06:00) stays a single record instead of being split into two
attendance intervals.

Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/opnsynid-hr-timesheet
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *Timesheet Attendance Shift*
6.  Install the module
