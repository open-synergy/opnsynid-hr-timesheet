=====================================================
Timesheet - Documenso Signing Integration
=====================================================

This module integrates **Timesheet** (``hr.timesheet``) with **Documenso**,
an open-source digital signature platform.

It adds a *Documenso* tab to the Timesheet form view, allowing users to
manage signature requests directly from the timesheet record.

Configuration
=============

No additional configuration is required. Install this module along with
``ssi_connector_documenso_signing`` and configure the Documenso connector
through the system settings.

Usage
=====

Open any Timesheet record. A new **Documenso** tab will appear in the form
view, listing all signature requests linked to that record.
