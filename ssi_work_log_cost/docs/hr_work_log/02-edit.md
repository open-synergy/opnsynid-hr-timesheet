# Edit Work Log

## Additional Fields

If the actor has `show_cost_setting_ok` access (see `01-create`), the **Cost** tab's
fields — **Usage**, **Account**, **UoM**, **Currency**, **Pricelist**, **Product**,
**Price Unit**, and **Tax(es)** — can be changed the same way as described in
`01-create`.
